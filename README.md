# Google Maps Review Change Feed — docs, SDKs, and support

Public guide for the Apify Actor **[Google Maps Review Change Feed](https://apify.com/basta_compilar/google-maps-review-change-feed)**.

Monitor public Google Maps reviews across locations, keep history between scheduled runs, and get priority actions for unanswered negatives. Dataset export, webhooks, and email are included in the place check.

This repository is the user documentation. The Actor source code stays in a private repository.
